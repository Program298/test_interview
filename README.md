# test_interview
โดยได้ทำการทำมาทั้งหมด 3 หน้า แต่ในส่วนหน้า3นั้นตัว กราฟนั้นไม่สามารถทำอะไรได้จึงได้ข้ามส่วนนั้นและเปลี่ยนเป็นรูป
## Tech Stack
- Vue.js: v3.5.43
- Node.js: v22.23.1
- Vue Router: v4.6.4
- JavaScript
- Tailwind CSS: v4.3.3

## Project setup
ติดตั้ง dependencies ที่จำเป็นสำหรับโปรเจกต์
```
npm install
```

### Run Development Serve
รันโปรเจกต์สำหรับ Development
```
npm run serve
```
